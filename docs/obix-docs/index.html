👋 Hello OBIX — Hybrid

One page, two real OBIX component styles, zero build step. Open DevTools (F12) → Console to see what each one does under the hood.

DOP primitive · you own the render loop

1. createButton from obix-component-button

Returns plain { name, state, actions, render }. Nothing re-renders on its own — every action call is followed by a manual innerHTML = button.render(state), right here in this page's own script.

obix-core · a real custom element

2. defineElement from obix-core

Registers <obix-counter> as a genuine Web Component — shadow DOM, a declarative {state.count} / data-on-click template, and automatic re-rendering on every dispatch. No manual innerHTML anywhere in this section.
